# water-jug-problem
A Python-based Water Jug Problem project that uses the Breadth-First Search (BFS) algorithm to find the solution. It demonstrates how to fill, empty, and transfer water between two jugs to achieve the desired water quantity.
# 💧 Water Jug Problem Using Python

## 📌 Project Description
The Water Jug Problem is a classic Artificial Intelligence problem. This project is implemented using Python and the Breadth-First Search (BFS) algorithm to find the required amount of water using two jugs of different capacities.

## 🎯 Objective
To measure the target amount of water using two jugs by performing different operations.

## ⚙️ Technologies Used
- Python
- Artificial Intelligence
- Breadth-First Search (BFS)

## 🧪 Example
- Jug 1 Capacity: 4 Litres
- Jug 2 Capacity: 3 Litres
- Target Amount: 2 Litres

## 🔑 Operations
1. Fill a jug completely.
2. Empty a jug.
3. Pour water from one jug into another.
4. Check whether the target amount is reached.

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the terminal.
4. Run the following command:

```bash
python water_jug.py
```

## 📤 Expected Output

```text
Target reached!
```
